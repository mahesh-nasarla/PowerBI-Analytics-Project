# Retail Bank Transaction Analysis | Power BI

## Project Overview

This project is about analyzing retail banking data using Microsoft Power BI.

The main goal is to understand customer behaviour, account activity, transaction patterns, loan performance, and card usage through interactive dashboards.

I used multiple banking datasets, cleaned the data, created relationships between tables, and built dashboards to find useful business insights.

## Project Objectives

- Understand customer details and customer activity.
- Analyze account balances and account usage.
- Track transaction trends and patterns.
- Monitor loan performance and delayed payments.
- Analyze card usage and customer engagement.
- Identify useful business insights from banking data.

## Tools and Technologies

- **Power BI** – Creating interactive dashboards and reports.
- **Power Query** – Cleaning and transforming data.
- **DAX** – Creating measures, calculated columns, and KPIs.
- **Data Modeling** – Creating relationships between tables.
- **Time Intelligence** – Analyzing data across different time periods.

## Dataset Details

This project contains 8 datasets:

| Dataset | Records | Description |
|---|---:|---|
| Customers | 500 | Customer details |
| Accounts | 700 | Account information and balances |
| Branches | 40 | Bank branch details |
| Transactions | 5,000 | Customer transaction records |
| Loans | 300 | Loan information |
| Loan Payments | 2,000 | Loan repayment details |
| Cards | 600 | Customer card information |
| Date Table | Calendar data | Used for date-based analysis |

## Data Cleaning and Transformation

I used Power Query to prepare the datasets for analysis.

- Checked and handled missing values.
- Corrected data types.
- Standardized column names and categories.
- Cleaned and prepared tables.
- Loaded the cleaned data into Power BI.

## Dashboard Pages

### 1. Customer Segmentation and Activity Analysis
Analyzes customer details, customer segments, and activity status to understand the customer base.

### 2. Account Usage and Branch Performance
Shows account balances, active accounts, interest rates, and branch performance.

### 3. Transaction Trends and Pattern Analysis
Analyzes transaction amounts, transaction types, customer activity, and transaction trends over time.

### 4. Loan Performance and Repayment Analysis
Tracks total loan amounts, outstanding balances, repayment activity, and delayed payments.

### 5. Card Usage and Product Engagement
Analyzes card activity, card types, credit limits, outstanding balances, and customer card usage.
